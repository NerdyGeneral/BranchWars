# Branch Wars — V2 release

Connected Company Banking milestone · September 7, 2026.

V2 is the package name, not a reset of campaign versions. New Financial Group
campaigns use rules 2 / save 9.1. Existing campaigns retain their rules.
This is a playable engineering milestone, not the completed banking-empire blueprint.

## Launch

Keep all files in this folder together. The hidden .gitattributes file preserves
the verified bytes when Git checks out this package on Windows.

- Windows local play: double-click **OPEN_BRANCH_WARS.bat**. Select Solo or
  Pass & Play. Alternatively open **BRANCH_WARS.html** in your browser.
- LAN/Intranet: run **OPEN_LAN_GAME.bat** on the host and keep its window open.
  Both players open the displayed server address. Create/join an Intranet Room,
  configure separate bank identities/colors in the lobby, and confirm readiness.
  Use a trusted local network; do not expose the server publicly or disable
  security protections.
- Repository Link: use the same build and an intended shared GitHub game-room
  repository, preferably private. Each player should use their own access token.
  Exchange the room code, never credentials. Keep the host browser open; use
  Resume/Retry and exports for recovery. This mode writes game messages to the
  chosen repository.
- Direct P2P: exchange the complete invitation and response codes. Both browsers
  must remain open; network restrictions can prevent a direct connection.

No Node.js, Python, developer dependencies or external JavaScript libraries are
needed to play. Windows LAN hosting uses the included PowerShell server.

## Try the new milestone

Expand **Optional systems**, check **Financial Group preview**, and confirm its
prerequisites. All previews remain unchecked by default. The deep pilot uses six
markets in two regions; it explicitly overrides the legacy map-size selector.
Campaign choices remain fixed after play starts.

Use **Group** for parent capital and corporate-client statements, **Credit** for
simultaneous lending, and **Markets** for renewable commercial-service mandates.
Winning a bank-service mandate does not buy the company.

## Keep your campaign

Export before replacing builds or moving between browser origins/computers.
Browser autosaves alone are not a portable backup. Import the exported campaign
into this build; keep the old package and export. In multiplayer the host owns
the authoritative export. Never distribute personal saves or room credentials.

See [release notes](RELEASE_NOTES.md), [verification](VERIFICATION.md), and
[file hashes](manifest.json). Real two-computer reliability and human enjoyment
remain acceptance checks; simulated tests do not establish either.
