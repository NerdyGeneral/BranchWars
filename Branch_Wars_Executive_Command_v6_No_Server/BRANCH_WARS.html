GitHub carries the game updates over normal web traffic. You do not need an IP address, an open port, or a connection between the two office networks.
FIRST-TIME GITHUB SETUP — OPEN THIS AND FOLLOW EACH NUMBER
Already made the organization and repository? Great—start at Step 2. This one-time setup is longer than starting future games.
  1. 1
    ORGANIZATION OWNER: PREPARE THE REPOSITORY

    Use a private repository inside your organization. If it is brand new, add a README so the repository has a working default branch. Do not protect that branch against direct file updates.

  2. 2
    ORGANIZATION OWNER: ADD THE OTHER PLAYER

    In the organization, open People → Invite member. After they accept, give that member Write access to the game repository.

    Important: They must be an organization member—not only an outside collaborator—or their fine-grained token may not work.

    GitHub instructions: invite an organization member ↗
  3. 3
    BOTH PLAYERS: MAKE YOUR OWN TOKEN

    Each person opens the token page below and chooses:

    Token name: Branch Wars
    Resource owner: your shared organization
    Repository access: Only select repositories → choose the game repository
    Repository permissions: Contents → Read and write

    Leave every other permission alone, generate the token, and copy it. GitHub shows it only once.

    Open GitHub's fine-grained token page ↗
  4. 4
    ORGANIZATION OWNER: APPROVE THE OTHER PLAYER'S TOKEN

    GitHub normally marks a member's new token as Pending. Go to Organization Settings → Personal access tokens → Pending requests, open their request, and select Approve. The organization owner’s own token normally does not need approval.

    GitHub instructions: approve a token request ↗
  5. 5
    START THE GAME BELOW

    The host enters OrganizationName/RepositoryName and their own token, then selects Open Room. Send the resulting join code—not the token—to the other player. They paste the code, enter their own token, and select Join Room.

    Using regular GitHub.com? Leave API Address blank; the game automatically uses https://api.github.com. That field is only for a company-hosted GitHub Enterprise Server.

TREAT A TOKEN LIKE A PASSWORD. Never email, message, or read it to the other player. Each player uses their own. The game keeps it only for the current browser session; Forget Session Token removes it sooner.
