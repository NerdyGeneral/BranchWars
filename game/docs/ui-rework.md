# Superseded UI proposal

The former cadence-band navigation proposal is **superseded**. It is not active implementation guidance.

The approved direction keeps useful subject grouping and puts actions beside their objects: market construction, office staffing/renovation, opportunity commitments, product terms and subsidiary management. Reduce scrolling through summaries and contextual inspectors, not another layer of unrelated menus.

Read [the current UI requirements](expanded-edition-goal.md) and [implementation ledger](v3-usability.md). The [complete original proposal and staffing analysis](archive/superseded-ui-rework-2026-09-13.md) remain available as historical evidence. This stable page is retained so existing links do not break.
