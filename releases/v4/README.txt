BRANCH WARS V4 - EXPANDED PLAYTEST (v4.0.0-rc1)

START
Extract the ZIP first and keep all six files together. Open OPEN_BRANCH_WARS.bat
on Windows, or open BRANCH_WARS.html directly. No installation is required.
The updated guide and playtest notes are separate assets on the V4 release page.

EDITIONS
Choose Core for original banking rivalry, or Expanded for the integrated regional
bank/Financial Group systems. Expanded adds products, research and delivery,
departments and specialist staffing, evolving facilities and shared rooms,
advertising and customer relationships, investment/agency operations, corporate
ownership and qualified company lending. New Expanded campaigns use save9.28.
V4 is the distribution name, not a replacement save-format version.
Rules stay fixed after starting. Older supported saves retain their own rules;
importing an older campaign does not add Expanded features automatically.

PLAY WITH A FRIEND
Both players should download this same V4 package. Choose names and visibly
different colors in the shared lobby, review the host settings, and both confirm.
LAN: the host runs OPEN_LAN_GAME.bat and keeps the server window open. Both players
use the displayed address and create/join an Intranet room on a trusted network.
Do not expose the server to the public Internet or disable security protections.
GitHub room: use your own tokens for the intended shared repository; prefer a
private repository. Share room codes, never tokens. Keep the host browser open.
Direct link: exchange the complete invitation and response. Network restrictions
may require using LAN or a GitHub room instead. No public relay is included.

BACK UP FIRST
Export from the old version before moving. Keep the old folder and the export.
Browser storage is tied to its original browser/address, so use Import when
moving. The multiplayer host owns the authoritative campaign export.
Keep private saves and credentials out of source repositories and public reports.

PLAYTEST STATUS
This is a testable development snapshot, not the completed blueprint or a full
release certification. The affected integration tests and simulated transports
pass; the final Windows gate, complete balance matrix, browser acceptance and
real two-computer testing remain outstanding. The latest ordinary balance run
recorded 108 months before interruption; it is NOT a completed 120/480-month pass.
The V3 PDF manual describes the older V3 build, not every V4 feature. Use the V4
quick-start and current development guides; a comprehensive V4 manual is pending.
National Empire and insurance underwriting remain deferred.

INTEGRITY
manifest.json records byte sizes and SHA-256 hashes for the other five files.
No campaign save, token, private diagnostic dump or development dependency is
included. Hashes identify file contents, not gameplay quality or authenticity.
