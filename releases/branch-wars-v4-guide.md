# Branch Wars V4 — playtest quick-start

This is a guide to the **v4.0.0-rc1 playtest**, not the finished comprehensive manual.

## Start safely

1. Export your current campaign and keep your old game folder.
2. Extract `branch-wars-v4.zip`. Keep its six files together.
3. Open `OPEN_BRANCH_WARS.bat`, or the HTML file directly.
4. Start a fresh **Expanded** campaign to test the complete integrated rules. Choose Core for the original experience. Imported campaigns retain their original rules.

V4 is the package label. New Expanded campaigns use save format9.28; do not edit a save's version number.

## Important banking distinctions

- Deposits are funding liabilities, not profit. Loan advances exchange cash for a loan asset; they are not earnings.
- Acquiring a company, banking it and lending to it are different relationships. A business does not automatically need or qualify for every product.
- Staff and specialist time are finite. Existing servicing, projects and new business compete for capacity.
- A building is not a license, a staffed service or a free customer book. New capacity still needs funding, qualified people and demand.
- Investment customer assets are not spendable bank or subsidiary cash. Insurance agency commissions come from third-party carriers; underwriting is not included.
- Forecasts are conditional estimates. Rival decisions and future events may change the settled result.

## Multiplayer checklist

Use the identical V4 ZIP on both computers. Review names and distinct colors in the lobby. Host settings changes clear both readiness confirmations. If the other build cannot support the rules, update it rather than changing save metadata.

For LAN, keep the host server running and use its displayed address. For GitHub rooms, keep credentials private and use the intended shared repository. For direct links, both browsers must remain open. Export before a long break, and use the existing recovery controls rather than creating a second copy of the same active session.

## What to test and report

Try simultaneous construction in two markets, staff reallocation, a real company relationship followed by a loan offer, and a multiplayer save/rejoin. Include the package name, campaign month, game mode, action taken and expected/actual result. Export a reproduction only through a private channel; never include access tokens.
